How the LAUNCH data reaches the RBM website

AS OF 10 OCT 2026

Three places, one direction: our team prepares and approves → one public data file → RBM's dashboard pages show it.

1 · Our workspace (private)

Collect, check and approve

launch-development-test
  1. 1Information comes in from public sources: WHO, national registers, trials (the map uses reliable sources only)
  2. 2A team member proposes a change
  3. 3Someone else reviews and approves it
  4. 4It is translated into French, Portuguese and Spanish automatically
Run by: the LAUNCH team · private, only the team can see it
sent automatically after approval
2 · Public data file

One file with all the dashboard data

launch-data-test
  1. 1Holds every medicine, stage and source, in 4 languages
  2. 2Updated after each approval (RBM's pages show it within about 10 minutes)
  3. 3Every version is kept, so we can see what was public and when
Run by: updated automatically · public, anyone can read it
read on every visit
3 · RBM dashboard pages

What visitors see on RBM's site

launch-rbm-test
  1. 1English, French, Portuguese and Spanish pages, in RBM's look, on desktop and phone
  2. 2Shown inside RBM's website (/en, /fr, /pt; Spanish is ready for when RBM adds it)
  3. 3Always show the latest approved data, with no work on RBM's side
  4. 4Visitors can subscribe for updates or send feedback
Run by: handed over to RBM · built from our workspace, so a page change is made once for every language

A person approves every change

Nothing reaches the public file without review.

Mistakes are easy to undo

Undo the change, click "Publish now", and the public file is put right.
